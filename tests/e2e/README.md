# E2E テスト（自動テスト）

コピひろを実際のブラウザに読み込み、右クリック → メニュー選択 → クリップボードへのコピー → 通知（トースト）表示までを自動で確かめるテストです。ヘッドレス（画面なし）の Microsoft Edge を Chrome DevTools Protocol（CDP）で操作します。

- 必要なもの: Windows、Microsoft Edge（標準の場所にインストールされているもの）、Python 3（3.13 で動作確認。標準ライブラリだけで動くため、追加のインストールは不要です）
- 所要時間: すべて実行して 1〜2 分ほど
- 普段使っている Edge や Chrome、PC のクリップボードには影響しません。テスト用の Edge は新しい一時プロファイルで起動し、終了時にはテストが起動したプロセスだけを閉じます。クリップボードもヘッドレス Edge 内の専用のものを使います。

> **このテストだけでは公開前の確認になりません。** 実際の右クリックメニューの操作や、メニューの操作で Chrome が与える `activeTab` の権限は再現できないため、模擬しています（下の「`--emulate-activetab` について」）。公開前・更新前には、[store/README.md](../../store/README.md) の「手順 0. 動作確認」も実際の Google Chrome で行ってください。

## 実行方法

リポジトリのルートで実行します。

```powershell
python tests\e2e\run.py --emulate-activetab --only a,b,e,f,g,h,i,j,k --out $env:TEMP\copy-hiro-e2e.json
```

```powershell
python tests\e2e\run.py --emulate-activetab --only c --out $env:TEMP\copy-hiro-e2e-c.json
```

結果の一覧を見やすく表示するには:

```powershell
python tests\e2e\show.py $env:TEMP\copy-hiro-e2e.json
```

- 終了コードは、失敗（fail）やエラー（error）が 1 件でもあれば 1、なければ 0 です。
- グループ c・d（拡張機能の再読み込みとサービスワーカーの再起動を伴うもの）は、ほかのグループと別に実行してください。同じ実行でまとめて流すと、テスト用ブラウザ側の都合でサービスワーカーとの接続が切れ、以降のグループが error になることがあります（拡張機能の不具合ではありません）。

### 何をテストするか

| 指定 | テストする対象 |
| --- | --- |
| （指定なし） | このリポジトリの実行用ファイル（`manifest.json`、`background.js`、`content.js`、`icons/`）。開発中の確認に使います |
| `--zip dist\copy-hiro-v2.4.zip` | `scripts/package.ps1` で作った**提出用の zip そのもの**。アップロード前の最終確認に使います |
| `--ext <フォルダ>` | 任意の展開済みフォルダ |

どの場合も、一時フォルダ（`%TEMP%\copy-hiro-e2e`）にコピーしたものを読み込むため、元のファイルは変更されません。

### 主なオプション

| オプション | 内容 |
| --- | --- |
| `--emulate-activetab` | `activeTab` の権限を模擬します（下を参照）。**通常はこれを付けて実行します** |
| `--activetab-scope top` | `--emulate-activetab` の模擬範囲を、トップのページのオリジンだけにします。実際の `activeTab` により近い条件で、別オリジンの iframe の扱いを確かめられます |
| `--only a,b,…` | 実行するグループを選びます（下の表）。`--list` で一覧を表示します |
| `--port` / `--http-port` | テスト用 Edge のデバッグ用ポート（既定 9401）と、テストページ用サーバーのポート（既定はその次の番号）。使用中ならエラーで止まるので、別の番号を指定してください |
| `--strict` | 警告（warn）も失敗として扱います |
| `--out` | 結果の JSON をファイルにも保存します |
| `--keep` / `--verbose` | 一時プロファイルを残す / 詳しいログを出す（調査用） |

## テストの内容

| グループ | 内容 |
| --- | --- |
| a | https 相当のページで 4 つのメニューすべて。TSV / Markdown の出力を一字一句確認。表の外での右クリック、表のないページ |
| b | http:// のページ（`navigator.clipboard` が使えない環境）でのコピー |
| c | 拡張機能の更新（再読み込み）前から開いていたタブでの動作と、再読み込み前後のエラーの有無 |
| d | サービスワーカーの停止・再起動後の動作 |
| e | `about:blank`、`edge://version` など、動作できないページでエラーにならないこと |
| f | iframe、結合セル、入れ子の表、空の表、セル内のタブ文字、フレームセット、SVG、シャドウ DOM などの特殊なケース |
| g | iframe（同一オリジン / 別オリジン / srcdoc）の中で右クリックしたときに、その iframe の表だけが対象になること |
| h | 更新前から開いていたタブの iframe での動作（別オリジンの iframe では「ページを再読み込みしてからお試しください。」が出ること） |
| i | 表のセルの中に Web コンポーネント（シャドウ DOM）がある場合 |
| j | ページの読み込み中にメニューを選んだ場合（二重読み込みにならないこと） |
| k | コピーを妨げるスクリプトがあるページ |

期待するクリップボードの内容と通知の文言は [expected.json](expected.json) にあります。出力形式や通知の文言を意図して変えたときは、ここも合わせて直してください。メニューの ID と動作名は [run.py](run.py) の `MENU` にあります。テスト用のページは [pages/](pages/) にあります（`big.html?rows=20000&cols=8` は大きな表を手で試すためのページです）。

### 結果の見方

- **pass**: 期待どおり
- **fail / error**: 不具合、またはテストの実行に失敗。修正が必要です
- **warn**: 既知の制限による結果です。現時点では次の 4 件が出るのが正常です（掲載文や README の「注意事項・制限」に記載済み）
  - `c2`: 更新前から開いていたタブで最初に「このテーブル…」を選ぶと、「もう一度テーブルを右クリックしてからお試しください。」と表示される
  - `f2`: 結合セル（colspan / rowspan）は展開されない
  - `f4`: 空の表を選ぶと、空の文字列がコピーされ成功の通知が出る
  - `k_nonsecure_window`: http:// のページで、ページ側のスクリプトがコピーを妨げると「コピーに失敗しました。」になる
- **info**: 参考情報（判定なし）

## `--emulate-activetab` について

拡張機能は、右クリックメニューの操作で Chrome が一時的に与える `activeTab` の権限を使って、更新前から開いていたタブに `content.js` を読み込み直します。CDP からの操作ではこの権限が与えられないため、このオプションを付けると、一時コピーの `manifest.json` に `host_permissions` を追加して権限の代わりにします（リポジトリの `manifest.json` は変わりません）。

付けずに実行すると、更新前から開いていたタブのテスト（c1、c2、c2b、c2c、h 群、j1）は、権限がないため「何も起きない」結果になります。これはテスト環境の制約で、拡張機能の不具合ではありません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `run.py` | テスト本体（グループ a〜f と全体の制御） |
| `frames_ext.py` | iframe などのテスト（グループ g〜k） |
| `cdp.py` | CDP の通信部分（Python 標準ライブラリだけで書いた WebSocket クライアント） |
| `show.py` | 結果の JSON を一覧表示する補助スクリプト |
| `expected.json` | 期待するコピー結果と通知の文言 |
| `pages/` | テスト用のページ（テスト中だけ `127.0.0.1` で配信します） |

このフォルダは `scripts/package.ps1` が作る提出用の zip には含まれません。また、Python の `__pycache__` を作らないようにしてあります（`_` で始まる名前があると、Chrome がリポジトリのフォルダを拡張機能として読み込めなくなるため）。
