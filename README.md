# コピひろ

Webページ上のテーブルを右クリックだけでクリップボードにコピーできるChrome拡張機能です。

## 機能

右クリックメニューから以下の操作ができます。

- **このテーブルをコピー** — カーソル位置のテーブルをタブ区切りテキストとしてコピー（Excel・スプレッドシートへの貼り付けに最適）
- **このテーブルをMarkdownでコピー** — カーソル位置のテーブルをMarkdown形式でコピー
- **ページ上の全テーブルをコピー** — ページ内の全テーブルをタブ区切りテキストとしてまとめてコピー
- **ページ上の全テーブルをMarkdownでコピー** — ページ内の全テーブルをMarkdown形式でまとめてコピー

コピーが完了すると、画面右上にトースト通知で結果が表示されます。

## インストール方法

1. このリポジトリをダウンロード（またはクローン）する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択する

## 使い方

1. コピーしたいテーブルの上（またはページ内の任意の場所）で右クリックする
2. コンテキストメニューから目的のコピー方法を選択する
3. 任意のテキストエディタやスプレッドシートに貼り付ける

## ファイル構成

| ファイル | 説明 |
| --- | --- |
| `manifest.json` | 拡張機能の設定（Manifest V3） |
| `background.js` | コンテキストメニューの登録とクリックイベントの処理 |
| `content.js` | テーブルの検出、テキスト/Markdown変換、クリップボードへのコピー、トースト表示 |
| `icons/` | 拡張機能アイコン（16px, 48px, 128px） |

## 権限

- `contextMenus` — 右クリックメニューへの項目追加
- `clipboardWrite` — クリップボードへのコピー

## バージョン

現在のバージョン: 2.3
