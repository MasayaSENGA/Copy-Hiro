# コピひろ

Web ページ上の表（テーブル）を、右クリックメニューからクリップボードにコピーできる Chrome 拡張機能です。タブ区切りテキスト（TSV）と Markdown の 2 つの形式に対応しています。

## 機能

表の上で右クリックし、メニューの「コピひろ」から次の操作を選べます。

- **このテーブルをコピー** — 右クリックした表を、タブ区切りテキスト（TSV）としてコピーします。Excel やスプレッドシートに貼り付けると、セルごとに分かれて入ります。
- **このテーブルをMarkdownでコピー** — 右クリックした表を、Markdown の表としてコピーします。
- **ページ上の全テーブルをコピー** — ページ内のすべての表を、タブ区切りテキストとしてまとめてコピーします。
- **ページ上の全テーブルをMarkdownでコピー** — ページ内のすべての表を、Markdown としてまとめてコピーします。

コピーの結果（コピーできたか、表が見つからなかったかなど）は、画面右上の通知（約 3 秒で消えます）でお知らせします。iframe（ページ内に埋め込まれた別のページ）の中の表も、iframe の中で右クリックすればコピーできます（通知は iframe の枠の右上に出ます）。

## Chrome ウェブストアからインストール

1. Chrome ウェブストアのコピひろのページを開く: https://chromewebstore.google.com/detail/dkhjplkghelbibkbjbohafjpjgnmeacf
2. 「Chrome に追加」をクリックし、確認画面で「拡張機能を追加」をクリックする

インストール時に表示される警告については、下の「権限」を参照してください。

2026年10月5日時点でストアに公開しているのは 2.3 で、この README が説明している 2.4（iframe の中の表、http:// のページ、インストール前から開いていたタブへの対応など）を審査中です。このリポジトリの 2.4.1 は 2.4 から機能の変更がない版で、2.4 の審査が終わってから提出します。

## 開発版のインストール（デベロッパー モード）

ストアを使わずに、手元のリポジトリから直接読み込む方法です（このリポジトリは非公開です）。

1. このリポジトリをクローンする
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダ（`manifest.json` があるフォルダ）を選択する

## 使い方

1. コピーしたい表の上で右クリックする（「ページ上の全テーブル…」の 2 項目は、ページ内のどこで右クリックしても使えます）
2. メニューの「コピひろ」から、目的のコピー方法を選ぶ
3. 画面右上に通知が表示されたら、テキストエディタや表計算ソフトなどに貼り付ける

ポップアップや設定画面はありません。操作はすべて右クリックメニューから行います。

通知の一覧:

| 通知 | 意味 |
| --- | --- |
| テーブルをコピーしました！ / テーブルをMarkdownでコピーしました！ / N 個のテーブルをコピーしました！ / N 個のテーブルをMarkdownでコピーしました！ | コピーできました |
| テーブルが見つかりませんでした。 | 右クリックした位置、またはページに表がありません |
| もう一度テーブルを右クリックしてからお試しください。 | インストール（更新）前から開いていたタブです。もう一度表を右クリックしてから選んでください |
| ページを再読み込みしてからお試しください。 | インストール（更新）前から開いていたタブで、別のサイトから埋め込まれた iframe の中で選びました（ページの右上に出ます）。ページを再読み込みしてください |
| コピーに失敗しました。 | クリップボードに書き込めませんでした |

## 権限

| 権限 | 理由 |
| --- | --- |
| `contextMenus` | 右クリックメニューに 4 つのコピー項目を追加するため |
| `clipboardWrite` | 変換したテキストをクリップボードに書き込むため（http:// のページでのコピーにも使います。クリップボードの読み取りはしません） |
| `activeTab` | `content.js` がまだ読み込まれていないタブ（インストールや更新の前から開いていたタブなど）で、メニューを選んだときに、そのタブへ一時的にアクセスするため（一時的なアクセスが及ぶのは、タブのページ本体と同じオリジンだけです。別のオリジンの iframe では、再読み込みを案内します） |
| `scripting` | 上記の場合に、右クリックしたフレームへ `content.js` を読み込むため（読み込むのは拡張機能に同梱した `content.js` だけです） |
| すべてのサイトで動くコンテンツスクリプト（`content_scripts` の `<all_urls>`、`all_frames: true`、`match_about_blank: true`） | どのサイトでも、右クリックした位置の表を特定するため。iframe の中（srcdoc や about:blank の iframe を含む）でも動作します |

インストール時に、Chrome は 2 種類の警告を表示します（正確な文言は Chrome のバージョンや言語によって異なります）。すべてのサイトのデータを読み取り・変更できることについての警告はコンテンツスクリプトによるもの、コピー＆ペーストするデータを変更できることについての警告は `clipboardWrite` によるものです。`contextMenus`・`activeTab`・`scripting` では警告は表示されません。

## プライバシー

コピひろは、データの保存・外部への送信・アクセス解析を一切行いません。表のテキストは、メニューを選んだときにだけ読み取り、端末内で変換してクリップボードに書き込みます。右クリックした要素は、どの表が対象かを判断するために、ページのメモリ上で一時的に覚えておくだけです。

プライバシーポリシーは https://privacy.love-live.jp/ で公開しています。全拡張機能で共通のポリシーで、このリポジトリとは別の、プライバシーポリシー用のリポジトリで管理しています。

## 注意事項・制限

- Chrome の内部ページ（`chrome://` など）、Chrome ウェブストア、ほかの拡張機能のページ、Chrome に組み込まれた PDF ビューアでは動作しません（メニューを選んでも何も起こりません）。
- ローカルの HTML ファイル（`file://`）で使うには、拡張機能の詳細画面で「ファイルの URL へのアクセスを許可する」をオンにしてください。
- インストール（更新）前から開いていたタブでは、次の通知が出ることがあります。
  - 「このテーブル…」を最初に選んだとき: 「もう一度テーブルを右クリックしてからお試しください。」。もう一度表を右クリックすると使えます。
  - 別のサイトから埋め込まれた iframe の中で選んだとき: ページの右上に「ページを再読み込みしてからお試しください。」。ページを再読み込みすると使えます。
- コピーできるのは HTML の table 要素で作られた表です。div 要素などで表のように見せているものはコピーできません。
- 結合セル（colspan / rowspan）は展開しないため、貼り付けたときに列がずれることがあります。
- 「ページ上の全テーブル…」は、右クリックしたページ（iframe の中で右クリックした場合はその iframe）のすべての表が対象です。非表示（display:none）の表や、表の中に入れ子になった表も含まれます。ほかのフレームの表や、シャドウ DOM の中の表は含まれません。
- シャドウ DOM の中の表は「このテーブル…」でコピーできます。ただし、クローズドなシャドウ DOM の中の表には対応していません。また、セルの中の Web コンポーネントがシャドウ DOM の中に表示している文字はコピーされません。
- コピーするのは文字だけです（太字やリンクなどの書式、画像はコピーしません）。セル内の改行とタブは半角スペースに置き換えます。Markdown 形式では 1 行目を見出し行として扱い、セル内の `|` は `\|` に置き換え、列が足りない行は空のセルで補います。
- 行のない空の表をコピーすると、成功の通知が出ますが、クリップボードには空の文字列が入ります。
- http:// のページで、ページ側のスクリプトがコピー操作を止めている場合は、コピーできずに「コピーに失敗しました。」と表示されることがあります。
- コピーすると、クリップボードの内容は上書きされます。

## 開発者向け

- Chrome ウェブストアへの公開・更新の手順: [store/README.md](store/README.md)
- アップロード用の zip の作成（リポジトリのルートで実行。`dist/copy-hiro-v<バージョン>.zip` ができます）:

  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts\package.ps1
  ```

  詳しくは [scripts/package.ps1](scripts/package.ps1) の冒頭のコメントを参照してください。
- 自動テスト（ヘッドレス Edge を使う E2E テスト）: [tests/e2e/README.md](tests/e2e/README.md)
- 更新版を出すときは、`manifest.json` の `version` を前回より大きい番号にしてください。

## ファイル構成

| ファイル | 説明 |
| --- | --- |
| `manifest.json` | 拡張機能の設定（Manifest V3） |
| `background.js` | コンテキストメニューの登録とクリックイベントの処理（右クリックしたフレームへの指示、未読み込みのページへの `content.js` の読み込み、読み込めないときの再読み込みの案内） |
| `content.js` | 右クリックした要素の記録、表の検出、TSV / Markdown への変換、クリップボードへのコピー、通知（トースト）の表示 |
| `icons/` | 拡張機能アイコン（16px, 48px, 128px） |
| `scripts/` | Chrome ウェブストア用の zip を作るスクリプト（`package.ps1`） |
| `store/` | Chrome ウェブストアの掲載文・画像・公開手順書 |
| `tests/e2e/` | 自動テスト（提出用の zip には含まれません） |

`dist/`（`package.ps1` の出力先）は Git では管理しません。
