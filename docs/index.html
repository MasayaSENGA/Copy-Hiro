コピひろ

Copy-Hiro ・ Chrome 拡張機能

Webページの表を、右クリックでそのままコピー。

コピひろは、Webページの表（テーブル）を右クリックメニューからコピーできる Chrome 拡張機能です。Excel やスプレッドシートに貼り付けるとセルごとに分かれるタブ区切り（TSV）形式と、Markdown 形式に対応しています。ページ上の全テーブルをまとめてコピーすることもできます。表のテキストはお使いの端末内で変換してクリップボードに書き込むだけで、保存や外部への送信は一切行いません。

Chrome ウェブストアからインストールできます。

使い方

  1. 表の上で右クリックします コピーしたい表のどこかで右クリックします。
  2. 「コピひろ」から項目を選びます メニューの「コピひろ」から「このテーブルをコピー」を選びます。Markdown 形式にするときは「このテーブルをMarkdownでコピー」を選びます。画面の右上に「テーブルをコピーしました！」と表示されたら完了です。
  3. 貼り付けます Excel やスプレッドシートに貼り付けると、セルごとに分かれて入ります。Markdown 形式は、Markdown を使えるエディタなどに貼り付けます。

ページ上の全テーブルをまとめてコピーするときは、ページの上で右クリックして「ページ上の全テーブルをコピー」または「ページ上の全テーブルをMarkdownでコピー」を選びます（表の上でなくてもかまいません）。

プライバシー

コピひろが扱うのは、コピーする表のテキストと、どの表を右クリックしたかを特定するための情報だけです。表のテキストは、お使いの端末内で変換してクリップボードに書き込むだけで、保存、外部への送信、第三者への提供は一切行いません。本拡張機能によるこれらの情報の使用は、Chrome ウェブストアのユーザーデータに関するポリシー（Chrome Web Store User Data Policy）に、Limited Use（使用の制限）の要件も含めて準拠しています。

プライバシーポリシーを読む

うまくいかないとき

  • 「もう一度テーブルを右クリックしてからお試しください。」と表示されたら、表を右クリックし直してから、もう一度項目を選んでください（コピひろのインストールや更新より前から開いていたページで表示されます）。
  • 「ページを再読み込みしてからお試しください。」と表示されたら、ページを再読み込みしてから、もう一度お試しください。
  • Chrome の設定画面（chrome:// で始まるページ）や Chrome ウェブストアなど、拡張機能が動作できないページでは使えません。
  • 端末内のファイル（file://）で使うには、拡張機能の詳細画面で「ファイルの URL へのアクセスを許可する」をオンにしてください。
  • 結合セル（colspan / rowspan）は展開しないため、貼り付け先で列がずれることがあります。

Copy-Hiro (English)

Copy-Hiro (コピひろ) is a Chrome extension that copies tables on web pages from the right-click menu. It supports tab-separated text (TSV), which splits into cells when pasted into Excel or a spreadsheet, and Markdown. It can also copy all tables on a page at once. The menu items and notices are in Japanese.

How to use

  1. Right-click a table on a web page.
  2. In the コピひろ menu, choose 「このテーブルをコピー」 (Copy this table) or 「このテーブルをMarkdownでコピー」 (Copy this table as Markdown). A notice appears in the top-right corner when the table has been copied.
  3. Paste it into Excel, a spreadsheet, or a text editor.

You can get the extension from the Chrome Web Store (see the link in the installation section above).

Privacy

Copy-Hiro handles only the text of the tables you copy and the information needed to identify which table you right-clicked. The text is converted on your device and written to your clipboard; it is never stored, sent anywhere, or shared with anyone. The extension's use of this information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
